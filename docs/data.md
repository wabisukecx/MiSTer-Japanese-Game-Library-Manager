# データ管理と取得元

## 保存先

標準の作業ディレクトリは `work/` です。別DBを指定したGUIでは、主な管理データもそのDBの隣に保存します。
CLIの画像キャッシュは各コマンドの `--cache` で指定し、既定は `work/artwork` です。

| 場所 | 内容 |
|---|---|
| library.sqlite3 | ROM登録、名前候補と確定名、名前の判断履歴、画像候補と選択、補正履歴、GUI設定 |
| title-db | GUIで書き出した日本語名DBとマージ結果JSONの標準保存先 |
| images/機種 | Skraper出力からコピーした管理画像 |
| artwork-edits | 向きを補正した画像コピー |
| metadata/retronian | 日本語名DBの機種別キャッシュとNOTICE.txt |
| metadata/redump | Redump Local Namesの機種別キャッシュとNOTICE.txt |
| metadata/gamedatabase | GameDataBase by PigSaintの機種別キャッシュとNOTICE.txt |
| artwork | CLIから取得した画像・検索キャッシュ |
| transfer-backups | 一括転送前のデータと復旧記録 |
| title-setup | 別名設定確認、プレビュー、名前単独転送のバックアップ |

ROM本体は登録元フォルダーに残し、DBには絶対パスを保存します。workだけではROMやSkraperを含む環境全体のバックアップにはなりません。
管理画像を手作業で移動するとDB参照が切れます。GUIは一覧読み込み時に欠落参照を除去します。

## バックアップと整理

アプリを終了して、DBと管理画像・補正画像・転送バックアップをまとめて保存してください。
外部ROMとSkraperの設定は、それぞれの保存先から別途バックアップします。
PC内や実機に残る転送バックアップは、表示確認と復旧が済むまで保持します。

Pythonの `__pycache__`、ビルド出力、テストログは再生成可能です。
取得した日本語名DBも再取得できますが、ネットワークに接続できない間の照合には既存キャッシュを使います。
画像候補や補正コピーは、DBが参照していないことを確認せず削除しないでください。

## 日本語名データ

登録済みROMの候補・確定名・出典・判断履歴は[日本語名DB JSON](title-db.md)として書き出し、複数のJSONをマージできます。取得元DB全体の再配布や公開サービス化を行う機能ではありません。元データの利用条件を保持し、ユーザーの判断にツールのMITライセンスを自動適用しません。

候補には [Retronian GameDB](https://github.com/retronian/retronian-gamedb) のデータを使用します。
データのライセンス表記はCC BY-SA 4.0です。取得時にNOTICE.txtを保存し、候補にも出典URL・上流の出所・ライセンスを保持します。
取得データはソースに同梱しません。再利用・再配布時は取得したNOTICEと提供元の条件を確認してください。

PCエンジン CD-ROM²・PlayStation・セガサターンでは [Redump Local Names](https://github.com/yingw/redump-local-names) の公開JSONも取得し、Retronianの候補と併用します。このJSONは旧Redump.orgから抽出された第三者の対応表で、Redump.infoの最新DBを直接取得するものではありません。キャッシュには取得URL・取得日時・元DATの日付を保存します。元DATの日付とキャッシュの取得日は別です。
RetronianではHuCARDとCD-ROM²が同じ `pce` カタログに収録されるため、そのキャッシュを共有します。RedumpはCD用カタログを `metadata/redump/pcecd.json` に保存します。登録・画像・転送先は `PCE` と `PCECD` で分かれます。
メガCDでもRedump Local Namesの専用カタログを使用します。
[現在のRedump公式案内](https://redump.info/about)はメタデータをpublic domainとしています。第三者の対応表自体は独自ライセンスを示さず、元のRedumpの条件を参照するよう案内しています。取得元とこの宣言のURLはキャッシュ・候補に記録します。画像・ROM・サイトのコードには適用しません。

ファミコン、スーパーファミコン、GB・GBC・GBA、N64、メガドライブ、メガCD、サターン、PCエンジン、CD-ROM²でも [GameDataBase by PigSaint](https://github.com/PigSaint/GameDataBase) を補完用に併用します。ディスクシステム、SG-1000、マークIII、ゲームギア、32X、ネオジオポケット／カラー、バーチャルボーイは同DBを主な取得元とします。[ライセンスはCC BY 4.0](https://github.com/PigSaint/GameDataBase/blob/main/LICENSE)です。国内版のレコードから日本語のパッケージ表記を選び、なければ日本語のタイトル画面表記を使います。日本語が未収録のレコードは変換候補にしません。
GameDataBaseではSHA-256一致を優先します。タイトル名だけの一致は地域・版を保証しない低い一致度の候補として表示します。GUIでは単一表記の候補を根拠とともに確認画面に表示し、利用者が保存または転送を決定したときに確定します。元データの日本語名を抽出・JSONに変換した旨、PigSaintの帰属、元CSVへのリンク、ライセンスをキャッシュのNOTICEと候補に残します。生のデータは同梱しません。
ネオジオポケット／カラーは元CSVを共有しますが、互換性タグで対象を分け、モノクロ機にカラー専用タイトルを提案しません。ROMの拡張子が違うため、登録と画像の作業設定もそれぞれに保持します。

機種ごとに、対応データのあるDBをすべて独立して照合します。サターンとCD-ROM²は3つのDBを併用します。DBに未収録の機種や、MiSTer公式未対応の機種は対応対象外です。

候補の元の表記・出典・ライセンス・取得日時は別々に保存します。画面上では全角・半角と空白だけの違いを同じ候補にまとめ、元の表記と全出典をスクロールして確認できます。記号、副題、読み方の違いはまとめません。同じ候補の代表表記は最も強い照合結果の原表記を使い、同順位なら取得元の既定順を保ちます。確定済みの表記は保持します。
ROM内容のSHA-256一致、ROM名一致、正規化タイトル一致の順に候補を表示します。内容一致の候補が1つの表記に絞れる場合は「推奨・ROM内容一致」と表示しますが、異なる表記が残る限り個別確認が必要です。同じROM内容に異なる日本語名が付いている場合も自動選択せず、DBの多数決も行いません。
GUIの確認・転送画面では、表記をまとめた候補が1種類だけなら弱い根拠のものも表示し、利用者の決定後に採用します。異なる表記があれば自動で採用せず、未確定なら日本語名を追加しません。通常の照合処理だけでは確定しません。弱い根拠の採用は判断履歴にbatch_confirmed_weakとして残します。プレビュー後に競合候補が増えた場合も、実際の保存・転送前に拒否します。
RedumpはDAT名による照合で、CHDの内容一致を保証しません。地域・版・ディスクのタグを除いた照合は低い一致度の候補になります。
一部のDBを取得できなくても、取得できたDBで照合を続けます。取得失敗したDBの既存候補と手動候補は保持し、GUIで取得失敗を表示します。すべて取得できなかった場合も既存候補を保持します。

機種別DBの通常キャッシュは7日です。更新に失敗して保存済みキャッシュを使った場合は、GUIにその旨を表示します。
確定済みの名前は自動変更せず、最新版との比較から選択したものだけを更新します。更新候補を提案するのは、取得失敗や古いキャッシュの利用がなく、出典間に競合のない強い候補が1つの名前に揃う場合です。全角・半角や空白だけの差は更新を提案しません。

## 画像の取得元

- [Skraper](https://www.skraper.net/): 外部ツールにScreenScraperのユーザーアカウントを設定して取得し、本アプリへPNGを取り込み。[初回設定](setup.md#4-screenscraperに登録しskraperでログインする)
- [Libretro Thumbnails](https://github.com/libretro-thumbnails): 正確なカタログ名を使うCLI取得
- [ScreenScraper](https://www.screenscraper.fr/): 開発者・利用者の認証を使うCLI取得

取得画像は各権利者・提供元の条件に従って扱ってください。画像は本プロジェクトに同梱しません。
地域タグやJPという要求だけで日本版画像と判断せず、内容・表記・向きを確認します。

## 認証と公開範囲

GUIで入力したMiSTerのIPとFTPユーザーは、次回の入力補助のため library.sqlite3 の設定に保存します。FTPパスワードは、接続ダイアログの「パスワードを保存する」を選んだ場合だけ保存します。保存するのはWindows DPAPIで暗号化した値で、平文では保存せず、同じWindowsアカウントでしか復号できません。DPAPIを使えない環境ではパスワードは保存しません。転送記録（transfer.json）にはパスワードを含めず、IPだけを記録します。CLIのパスワードは従来どおり保存しません。
ScreenScraperの認証は対話入力または環境変数を使います。認証付きURLを画像の保存キーや出典へ残しません。

`.gitignore` はwork、ローカルDB、環境変数ファイル、Skraper設定、ROM、取得アーカイブ、ビルド出力を除外します。
メガドライブの `.md` はMarkdown文書と拡張子が共通なので、ROMはwork・roms・リポジトリ外のフォルダーへ置いてください。
`.gitignore` は既に追跡済みのファイルには作用しません。公開するファイルはGitの差分で確認します。
